Appliance icons in this folder are sourced from the
[PlateUp! Planner](https://github.com/plateupplanner/plateupplanner.github.io) community project
(`public/images/display/`), not drawn or extracted by this project. That repo has no LICENSE file;
committing these here was a deliberate decision (not the default recommendation) made 2026-08-09 —
see `docs/project-history.md` for context if revisiting.

Filenames match the appliance's resolved display name, kebab-cased (see `iconPathFor` in
`js/app.js`) — add new icons here following that convention if a future setting introduces an
appliance ID not already covered.
